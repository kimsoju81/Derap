# 🧭 Derap — Navigasi Jalan Raya Malaysia

**Derap** ialah aplikasi navigasi jalan raya pintar Malaysia yang dibina sepenuhnya di atas ekosistem teknologi sumber terbuka (*open-source*). Direka dengan fokus kepada kelajuan, ketepatan laluan tempatan, dan ketiadaan iklan yang mengganggu pemanduan.

🔗 **Pautan Pelepasan Terkini:** [Muat Turun Derap (Release: Navigation)](https://github.com/kimsoju81/Derap/releases/tag/Navigation)  
🌐 **Demo Web:** [derap-studio.ai.studio](https://derap-studio.ai.studio/)

---

## 🚀 Mengapa Derap?

Kebanyakan aplikasi navigasi komersial hari ini dipenuhi dengan iklan *pop-up* dan menjejaki data pergerakan pengguna secara agresif. **Derap** hadir sebagai alternatif tempatan yang bersih, ringan, dan terus kepada fungsi utama: **membawa anda dari titik A ke titik B dengan lancar.**

* **Sifar Iklan:** Skrin peta yang bersih tanpa gangguan visual semasa memandu.
* **Privasi Diutamakan:** Pergerakan GPS anda tidak disimpan atau dijual kepada rangkaian pengiklanan.
* **Reka Bentuk Fokus Pemandu:** Gabungan warna kontras tinggi dan tipografi teknikal (*Plus Jakarta Sans* & *JetBrains Mono*) untuk bacaan pantas jarak, kelajuan, dan anggaran masa tiba (ETA).

---

## 🛠️ Seni Bina Teknologi (Tech Stack)

Derap menggabungkan teknologi web moden bersama tiga enjin georuang sumber terbuka terbaik dunia:

| Komponen | Teknologi | Fungsi Utama |
| :--- | :--- | :--- |
| **Peta Asas** | [OpenStreetMap (OSM)](https://www.openstreetmap.org/) | Data pemetaan jalan raya Malaysia yang dikemas kini oleh komuniti. |
| **Enjin Laluan** | [OSRM](http://project-osrm.org/) | Pengiraan laluan terpantas dan *turn-by-turn routing* dalam milisaat. |
| **Carian Lokasi** | [Nominatim](https://nominatim.org/) | *Geocoding* & *reverse geocoding* untuk carian alamat dan mercu tanda. |
| **Frontend** | React + Vite + Tailwind CSS | Antara muka pengguna (UI) yang responsif dan berprestasi tinggi. |
